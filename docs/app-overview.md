# TeamFlow at a glance

TeamFlow is intended to help teams plan and coordinate project work in one place. Teams can organize projects, break work into tasks, assign responsibilities, and follow progress so everyone can see what needs attention.

## Who it is for

Small teams that need a straightforward shared view of their projects, task ownership, and progress.

## What the app is meant to do

- Keep project work and its tasks organized.
- Make task ownership clear by assigning responsibilities.
- Help teammates track progress and coordinate their work.

## How it is built

- **Frontend:** React, with Vite for local development and builds.
- **Backend:** Node.js and Express, serving the API.

## Current state

The project is at an early starter stage. The frontend currently displays a placeholder “Hello World!” screen, and the backend currently exposes an API health-check endpoint at `GET /api/health`. Project, task, assignment, and progress-management features are part of the intended product, but are not implemented yet. There is currently no database integration in the backend.
